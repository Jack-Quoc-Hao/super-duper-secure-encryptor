# Super duper secure encryptor
This repository contains a encryptor and decryptor.
# How to use
Run encryptor.py and enter your text, then copy the key and the encrypted message. Then,send the encrypted message and the key to someone you want them to decrypt. He/She will need to run decryptor.py and copy-paste the key and the encrypted message, and the output will be the text you entered.Also, you and he/she will need to run the command "pip install cryptography" before running encryptor.py or decryptor.py.
